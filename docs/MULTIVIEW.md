# Four-view layout

The global **View layout** selector supports **Four views (2×2)** and **One enlarged view**. It works across Calibration, Scenario, Camera Performance, 2.5D Neighbors, and Results.

Use **Ctrl+G** for the 2×2 grid, **Ctrl+L** for one enlarged photo, and **Ctrl+1..4** to select the active camera. Double-click a photograph to toggle the layout when an annotation tool is not active. Click **Fit image** to restore zoom and positioning. Zoom changes only the Qt viewport; annotation coordinates stay in native photo pixels.

In Camera Performance, previewing a synchronized proposal swaps the 3D-camera overlays only; the photographs are unchanged until and unless you explicitly accept the proposal, and even then the original photos are never overwritten.
