# Result Viewer

Select a saved run in **Results** and choose:

- **Original**: unchanged input photography.
- **Generated**: final generated photos, including optional enhancements when enabled.
- **Compare**: aligned original/generated photographs with a vertical reveal slider.
- **Base**: Stable Diffusion output before façade/roof enhancements.
- **Geometry preview · CPU**: geometric masks and structural overlays, not a generated photorealistic image.

The top layout selector enables 2×2 or an enlarged single view. The app can save a four-view montage or export the selected run. Missing generated views remain marked as missing; previews are never substituted silently for final images.
